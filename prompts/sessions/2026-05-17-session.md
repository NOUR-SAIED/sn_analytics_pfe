## Key Insight From This Session
The current Silver table is still a **wide staging layer**, not a proper domain model.

It must now evolve into **structured Silver entities** to support Gold KPIs.

---

## Next Step (Critical)

### Phase 2: Build Silver Domain Models

Start splitting the wide Silver table into reusable business entities:

- `silver_cases`
  - normalized incident/case-level entity
  - core SLA timestamps and lifecycle fields

- `silver_users`
  - user-level attributes (agents, requesters)

- `silver_assignments` (optional)
  - mapping between cases and assigned agents

Goal:
Create a clean relational Silver layer that removes redundancy and prepares for Gold KPI aggregation.
